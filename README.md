# Xnet Design System (Token Repository)

এটি হলো Xnet ব্রান্ডের **"Single Source of Truth"** (একক ডেটা সোর্স) ডিজাইন সিস্টেম রিপোজিটরি।

## সিস্টেমটি কীভাবে কাজ করে?
এই রিপোজিটরিতে 	okens/tokens.json ফাইলে আমাদের মূল ডিজাইন টোকেনগুলো (যেমন কালার, বাটন সাইজ, ফন্ট ইত্যাদি) রাখা আছে।

যখনই আপনি 	okens.json ফাইলে কোনো মান পরিবর্তন করবেন (যেমন কোনো বাটনের সাইজ 100dp থেকে 150dp করবেন), গিটহাব অ্যাকশনস (GitHub Actions) বট সাথে সাথে ব্যাকগ্রাউন্ডে চালু হয়ে যাবে এবং scripts/generate_platforms.py স্ক্রিপ্টটি রান করবে।

স্ক্রিপ্টটি রান হওয়ার পর সে স্বয়ংক্রিয়ভাবে তিনটি প্ল্যাটফর্মের জন্য কোড জেনারেট করে দেবে:
১. **Web (CSS):** platforms/web ফোল্ডারে
২. **iOS (Swift):** platforms/ios ফোল্ডারে
৩. **Android (XML):** platforms/android ফোল্ডারে

## ডেভেলপারদের কাজ
ডেভেলপারদেরকে ম্যানুয়ালি কোনো কোড বা জেসন (JSON) ফাইল পরিবর্তন করতে হবে না। 
* **ওয়েব ডেভেলপার:** NPM এর মাধ্যমে আপডেট নেবে।
* **আইওএস ডেভেলপার:** Swift Package Manager (SPM) এর মাধ্যমে আপডেট নেবে।
* **অ্যান্ড্রয়েড ডেভেলপার:** Gradle ডিপেন্ডেন্সির মাধ্যমে আপডেট নেবে।

## ফাইল স্ট্রাকচার
- 	okens/tokens.json: মূল ডিজাইনের ডেটা (এখানে এডিট করতে হবে)।
- scripts/generate_platforms.py: পাইথন স্ক্রিপ্ট যা টোকেন থেকে কোড বানায়।
- platforms/: জেনারেট হওয়া ফাইলগুলোর গন্তব্য (এখানে হাত দেওয়ার প্রয়োজন নেই)।
- .github/workflows/generate.yml: গিটহাবের বট বা অটোমেশন সিস্টেম।
